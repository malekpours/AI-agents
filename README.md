# ایجنت‌های هوش مصنوعی برای کنشگران: دوره‌ی کارگاهی

یک دوره‌ی ۸ ماژوله برای فعالان مدنی و اجتماعی ایرانی — مبتنی بر تعامل، بدون نیاز به پیش‌زمینه‌ی فنی.

## چرا این دوره؟

ابزارهای هوش مصنوعی به بخشی از زندگی روزمره تبدیل شده‌اند، اما «ایجنت‌ها» مرز جدیدی هستند: نرم‌افزارهایی که به‌جای پاسخ دادن به یک سؤال، **نیابتاً عمل می‌کنند** — جست‌وجو می‌کنند، اسناد می‌نویسند، زمان‌بندی می‌کنند و با ابزارهای دیگر ارتباط برقرار می‌کنند. همین قدرت، ریسک‌های جدیدی برای کسانی ایجاد می‌کند که فعالیتشان حساس است: ایجنت اشتباهی می‌فهمد، داده به مقصد اشتباهی می‌رود، یا لایه‌ی امنیتی شما دور زده می‌شود.

این دوره هم **توانمندسازی** را آموزش می‌دهد و هم **کاهش آسیب** (Harm Reduction): چطور از این ابزارها با بیشترین سود و کمترین ریسک استفاده کنیم.

## ساختار پوشه‌ها

```
├── README.md            ← همین فایل
├── facilitator-guide.md ← راهنمای مدرس و کارگاه‌برگزار
├── slides/              ← اسلایدهای کارگاهی (HTML مستقل — تک‌فایل، بدون وابستگی)
├── handouts/            ← برگه‌های تمرین، قرارداد داده و چک‌لیست نهایی
├── modules/             ← متن کامل هر ماژول (مرجع مدرس و شرکت‌کننده‌ی جدی)
└── tools/               ← اسکریپت build (جاسازی قالب در اسلایدها)
```

## طراحی آموزشی

- **۸۰/۲۰:** حداکثر ۸۰٪ زمان صرف تعامل، ۲۰٪ ارائه.
- **داستان‌محور:** هر مفهوم با یک روایت جمعی شروع می‌شود («شبِ اطلاعیه»).
- **پرده‌بندی:** شرکت‌کنندگان شیوه‌ی کارشان را با هم به اشتراک نمی‌گذارند؛ مثال‌ها کلی است.
- **آگاهی‌رسانی به ریسک:** هیچ تمرینی مخاطب را مجبور به ورود داده‌ی واقعی حساس نمی‌کند.
- **حلقه‌ی بازخورد:** آخر هر جلسه، دو سؤال کوتاه: «کدام ابزار را امتحان می‌کنید؟» و «کدام ریسک شما را نگران کرد؟»

## نحوه‌ی اجرا

### ارائه‌ی اسلایدها

هر فایل اسلاید **کاملاً مستقل** است — قالب و موتور ناوبری داخل خودش جاسازی شده. کافی است فایل را در مرورگر باز کنید؛ نه سرور می‌خواهد، نه اینترنت:

```
slides/index.html   ← فهرست هر ۸ دک
slides/01-mabani.html  ...  slides/08-jam-bandi.html
```

کنترل‌ها: **← / →** یا **Space** حرکت · **Home/End** ابتدا و انتها · **F** تمام‌صفحه · **Esc** نمای فهرست · **P** حالت مدرس (یادداشت‌های سخنران هر اسلاید) · اسوایپ لمسی در تبلت.

### ویرایش قالب

طراحی مشترک در `slides/theme.css` و منطق ناوبری در `slides/deck.js` نگهداری می‌شود. بعد از هر تغییر، آن را در همه‌ی اسلایدها دوباره جاسازی کنید:

```bash
python3 tools/inline_assets.py
```

### محتوای حساس؟

اسلایدها تک‌فایل و آفلاین‌اند — برای محیط با نظارت اینترنتی، پوشه‌ی دوره را روی فلش منتقل کنید و از فایل‌های محلی ارائه بدهید. هیچ فایلی به سرویس بیرونی وابسته نیست.

## نکته‌ی مهم برای مدرس

ایجنت‌ها سریع تغییر می‌کنند. اسم‌ها و رابط‌های ابزارها ممکن است تا زمان ارائه عوض شده باشند. قبل از هر جلسه، بخش «به‌روزرسانی» در انتهای `facilitator-guide.md` را بخوانید و مثال‌ها را با وضعیت روز هماهنگ کنید.
