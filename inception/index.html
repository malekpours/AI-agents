واژه‌نامه تخصصی اصطلاحات کلیدی (Glossary)

عنوان فارسی اصطلاح انگلیسی (English Term) توضیحات مختصر
ایجنت هوش مصنوعی AI Agent سیستمی هوشمند که توانایی هدف‌گذاری، برنامه‌ریزی چندمرحله‌ای و استفاده از ابزارها برای انجام کارها را دارد.
مدل زبانی بزرگ Large Language Model (LLM) مغز پردازشی ایجنت که بر پایه الگوهای متنی آموزش دیده و پاسخ‌ها را تولید می‌کند.
وظیفه / کار Task هدف یا فرآیندی مشخص که کاربر از ایجنت می‌خواهد آن را به سرانجام برساند.
درخواست / پرامپت Prompt ورودی متنی، دستورالعمل یا چارچوبی که کاربر به مدل یا ایجنت می‌دهد.
ابزار Tool قابلیت‌های جانبی متصل به ایجنت مانند مرورگر وب، ماشین‌حساب، خواندن فایل یا ارسال ایمیل.
حافظه و زمینه Memory & Context اطلاعات نگهداری‌شده از گفت‌وگوها و سابقه کارها جهت حفظ انسجام در مراحل بعدی.
خودمختاری Autonomy میزان اختیاراتی که به ایجنت داده می‌شود تا بدون تایید مستقیم انسان اقدام کند.
نظارت انسانی Human-in-the-Loop (HITL) الگویی که در آن انسان در مراحل کلیدی، خروجی ایجنت را بررسی و تایید یا رد می‌کند.
رابط برنامه‌نویسی API (Application Programming Interface) پل ارتباطی میان ایجنت و سرویس‌های بیرونی جهت تبادل داده.
تزریق پرامپت Prompt Injection نوعی آسیب‌پذیری امنیتی که در آن ورودی‌های خبیثانه کنترل ایجنت را منحرف می‌کنند.
