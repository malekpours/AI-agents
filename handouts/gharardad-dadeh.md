# قرارداد داده‌ی گروهی — قالب قابل چاپ

> یک نسخه برای هر گروه تکمیل و به امضای همه‌ی اعضا برسد. هر سه ماه بازبینی شود.

```
════════════════════════════════════════════
       قرارداد داده‌ی گروه ____________
════════════════════════════════════════════

۱. داده‌ی حساس ما عبارت است از:
   ────────────────────────────────────────

۲. داده‌ی حساس هرگز وارد این ابزارها نمی‌شود:
   ────────────────────────────────────────

۳. داده‌ی حساس فقط روی این دستگاه‌ها/ابزارها کار می‌شود:
   ────────────────────────────────────────

۴. مراحل بی‌نام‌سازی پیش از ورود داده به هر ابزار:
   □ حذف نام‌ها و مشخصات تماس
   □ جایگزینی با کد (مثل «م.ک»، «شاهد ۱»)
   □ چک مشخصه‌های ترکیبی (شغل + شهر + تاریخ)
   □ سایر: ────────────────────────────────

۵. جدول رمز (کدها ↔ نام‌ها) اینجا نگهداری می‌شود:
   ────────────────────────────────────────

۶. اگر داده‌ای به اشتباه افشا شد، مراحل اطلاع‌رسانی:
   □ قطع دسترسی ایجنت/ابزار
   □ ارزیابی: چه داده‌ای، به کجا؟
   □ اطلاع به افراد آسیب‌پذیر (به روش امن)
   □ اصلاح تنظیمات
   □ یادنامه‌ی حادثه

۷. بازبینی بعدی این قرارداد: ____ / ____ / ______

امضاها:
   ─────────────    ─────────────    ─────────────
```

### سه پرسش پیش از هر ورود داده (یادآوری)

1. **چه کسی این را می‌بیند؟** (ایجنت؟ شرکت؟ واسط؟)
2. **اگر فردا عمومی شود، چه کسی آسیب می‌بیند؟**
3. **با داده‌ی بی‌نام‌شده هم می‌شود؟** بله ← بی‌نام‌سازی کن. نه ← ابزار محلی.
