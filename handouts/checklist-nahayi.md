# چک‌لیست نهایی — نسخه‌ی چاپی شرکت‌کننده

> راهنما: هر بند را علامت بزنید — **سبز** (انجام شد) / **زرد** (تا یک ماه) / **قرمز** (نمی‌کنم؛ دلیل را بنویسید). «نمی‌کنم» هم یک تصمیم آگاهانه است، فقط باید نوشته شود.

| | بند | سبز | زرد | قرمز + دلیل |
|---|------|-----|-----|--------------|

| | «سه پرسش پیش از ورود داده» برای همه آشناست | ☐ | ☐ | |
| | برای کار حساس، ابزار محلی/آفلاین تعیین شده | ☐ | ☐ | |
| **ایجنت‌ها** | هر ایجنت، کارت مشخصات دارد | ☐ | ☐ | |
| | تأیید انسانی برای ارسال/حذف/انتشار فعال است | ☐ | ☐ | |
| | ایجنت‌ها حداقل دسترسی دارند (فقط‌خواندن پیش‌فرض) | ☐ | ☐ | |
| | دستورالعمل سیستمی با قیدهای روشن نوشته شده | ☐ | ☐ | |

| | 2FA روی ایمیل و حساب‌های حیاتی فعال است | ☐ | ☐ | |
| | هویت‌ها با ایمیل جدا از هم جدا شده‌اند | ☐ | ☐ | |
| | کد تأیید بین همکاران تعریف شده | ☐ | ☐ | |
| | پروتکل از دست دادن دستگاه نوشته شده | ☐ | ☐ | |
