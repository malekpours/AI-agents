# چک‌لیست پایانی: آیا برای استفاده آماده‌ایم؟

این چک‌لیست جایگزین ارزیابی تخصصی نیست. از آن برای پیدا کردن پرسش‌های بی‌پاسخ استفاده کنید، نه برای اثبات اینکه ابزاری «کاملاً امن» است. اگر موضوعی روشن نیست، آن را علامت بزنید تا پیش از استفاده پیگیری شود.

برای هر ردیف یکی را انتخاب کنید: **روشن است**، **باید بررسی شود** یا **فعلاً انجام نمی‌دهیم**.

| موضوع | پرسش | روشن است | باید بررسی شود | فعلاً انجام نمی‌دهیم |
|---|---|:---:|:---:|:---:|
| هدف | می‌توانیم کار مشخصی را که از ابزار می‌خواهیم توضیح دهیم (Task). | ☐ | ☐ | ☐ |
| تناسب | می‌دانیم چرا این کار را به ایجنت می‌سپاریم و چه گزینه‌ی دیگری داریم. | ☐ | ☐ | ☐ |
| داده | می‌دانیم چه متنی وارد ابزار می‌شود و چه چیزی را می‌توان حذف کرد (Data Minimization). | ☐ | ☐ | ☐ |
| مجوز | اجازه‌ی استفاده از متن یا فایل را داریم. | ☐ | ☐ | ☐ |
| سرویس | شرایط و تنظیمات مهم سرویس را بررسی کرده‌ایم یا می‌دانیم چه چیزی نامعلوم است. | ☐ | ☐ | ☐ |
| دسترسی | ایجنت فقط به ابزارها و حساب‌های لازم دسترسی دارد. | ☐ | ☐ | ☐ |
| اختیار | ایجنت بدون تأیید انسان پیام نمی‌فرستد، منتشر نمی‌کند یا تصمیم مهمی نمی‌گیرد. | ☐ | ☐ | ☐ |
| آزمون | پاسخ‌های درست، نامعلوم و گمراه‌کننده را امتحان کرده‌ایم (Testing). | ☐ | ☐ | ☐ |
| بازبینی | فرد مشخصی پاسخ‌ها را پیش از استفاده بررسی می‌کند. | ☐ | ☐ | ☐ |
| خطا | می‌دانیم در صورت پاسخ نادرست یا رفتار غیرمنتظره چه کنیم (Incident Response). | ☐ | ☐ | ☐ |
| تداوم | اگر ابزار یا اینترنت در دسترس نبود، راه دیگری داریم. | ☐ | ☐ | ☐ |
| پیگیری | زمان بازبینی دوباره و مسئول آن مشخص است. | ☐ | ☐ | ☐ |

## پیش از انتشار متن تولیدشده

- [ ] ادعاهای مهم را با منبع اصلی یا منبع معتبر سنجیده‌ام (Fact-checking).
- [ ] نام‌ها، عددها، تاریخ‌ها و نقل‌قول‌ها را با متن مبنا مقایسه کرده‌ام.
- [ ] ترجمه را از نظر معنا، لحن و اصطلاح‌های محلی بازبینی کرده‌ام.
- [ ] مطمئن شده‌ام متن یا تصویر، اطلاعاتی را که نباید منتشر شود فاش نمی‌کند.
- [ ] خودم یا فرد مسئول نسخه‌ی نهایی را تأیید کرده است.
